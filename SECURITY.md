# Security

If you find a security problem in TLI Toolkit, its website (tlitoolkit.com) or its community server
(api.tlitoolkit.com), please email **[hello@tlitoolkit.com](mailto:hello@tlitoolkit.com)** instead of opening a public
issue. Say what you found and how to reproduce it; you'll get an answer within a few days.

Only download TLI Toolkit from [this repository's releases](https://github.com/SheF1k/tli-toolkit-releases/releases).
Each release lists the exe's SHA-256, and the app's updater checks it before it installs an update.
